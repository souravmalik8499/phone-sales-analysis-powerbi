# 📱 Phone Sales Analysis Dashboard – Power BI

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze
phone sales performance.

The dashboard provides insights into sales, quantity, transactions,
mobile models, brands, payment methods and time-based performance.

## 🛠️ Tools Used

- Power BI
- DAX
- Power Query
- Excel
- Data Modeling

## 📈 Dashboard Pages

### 1. Phone Sales Dashboard

Key KPIs:
- Total Sales
- Total Quantity
- Average Price
- Total Transactions

Analysis includes:
- Total Quantity by Month
- Sales by Mobile Model
- Transactions by Payment Method
- Sales by Day
- Rating Analysis
- Brand Performance
- Geographical Sales Analysis

### 2. MTD Report

The MTD report analyzes sales performance by:

- Year
- Quarter
- Month
- Day

### 3. Same Period Last Year

Comparison of:

- Current Year Sales
- Previous Year Sales
- Quarterly Performance
- Monthly Performance

## 📊 Key DAX Concepts

- MTD
- YTD
- Same Period Last Year
- CALCULATE
- FILTER
- DATEADD
- TOTALMTD
- TOTALYTD
